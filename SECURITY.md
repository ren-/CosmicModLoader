# Security

Found a security problem in the loader? Report it privately with
[Report a vulnerability](https://github.com/ren-/CosmicModLoader/security/advisories/new),
not in a public issue.

Only download the loader from this repo's [Releases](https://github.com/ren-/CosmicModLoader/releases).
Each release lists the zip's SHA-256 so you can check your download.
